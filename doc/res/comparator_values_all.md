# All Comparator Values **(71.44)**

The complete set of `<VALUE>` keys usable inside a `REQUIRES` block, i.e. the contents of the engine's `GVALUES.FACTION` value category. For the comparators themselves (`GREATER`, `GREATERE`, …) see [require.md](../config/require.md).

**Scope Caveat:** the engine has four value categories — `FACTION`, `REGION`, `INDU` (individual) and `ROYALTY` (`init/value/GVALUES.java:20-23`). Only `FACTION` is listed here. A `REQUIRES` block resolves against whichever category its owner registered, so region- and individual-scoped requires accept a *different* key set that is **not** in this file.

Content whose `REQUIRES` uses these FACTION keys: **techs** (`init/tech/TECH.java:71`), **player titles** (`PTitles.java:393`) and **levels** (`PLevels.java:179`), **events** (`EChoice`, `ECondition`, `EOccurence`), **room unlocks** (`RoomBlueprintImp.java:73`) and **room recipes** (`Industry.java:265`).

## Useful Notes

- **Several comparators in one `REQUIRES` are allowed and are ANDed.** Every key of the block is read as a comparator and each entry becomes its own lock (`Lockable.java:115-127`); `passes()` fails if any one fails (`Lockable.java:45-51`). Vanilla does this — see `player/titles/THE_GREAT.txt`.
- **No wildcards.** `GValueCat` supports a `*` prefix wildcard, but `REQUIRES` resolution uses the plain map lookup (`Lockable.java:145,166`), so `POPULATION_*_CITIZEN_I` will not match.
- **`_F` is a fraction of total population, not of the class.** `POPULATION_<RACE>_<CLASS>_F` computes `POP.tot(cl, r) / POP.tot(null, null)` (`SValues.java:202-213`). This changed in v71 — "100% of my citizens are race X" style checks that relied on a per-class denominator no longer behave as they did in v70.
- Boolean-ish values (`IS_PLAYER`, `STANCE_*`, `CLIMATE_*`, `PLAY_MODE_*`, `FACTION_IS_*`) compare against `1` / `0`.

Keys are grouped by prefix below. Within each group the engine's own order (`KeyMap.allSorted()`) is preserved, and the count in each heading is the number of keys in that block — **1758 total**. Group names are the literal key prefixes rather than flavour names, since the dump yields keys only (no display names or defaults).
